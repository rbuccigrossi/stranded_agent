# Plans

Use the built-in plan tools to make multi-step work visible and update it as
the task progresses.

- Create a plan when work has multiple dependent steps.
- Keep steps concrete and short.
- Mark exactly one step `in_progress` at a time.
- Mark a step `completed` only after verifying it.
- Update the plan when scope changes or a step is blocked.
- Do not create plans for trivial one-step requests.

When a plan is created or updated, the framework echoes it to the user. Keep
the tool update concise so the visible progress remains easy to follow.
