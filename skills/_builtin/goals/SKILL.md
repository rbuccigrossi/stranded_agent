# Goals

Use the goal tools when work needs an explicit objective beyond the current
turn.

- Create a goal only when the user requests an ongoing objective or the task
  clearly benefits from bounded iteration.
- State a concrete objective and optional token or step budget.
- Check the goal before continuing a resumed task.
- Mark it `complete` only when the objective is actually achieved.
- Mark it `blocked` only after the same blocker has recurred and no safe
  progress remains without user input or an external change.
- Pair goals with a plan when the work has multiple steps.
